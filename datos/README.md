# Datos

Registros reales capturados el 17/02/2025 con `pruebas/adquisicion_datos/registro_sensores_csv.py`, con el CubeSat
sobre la mesa (aceleración en Z ≈ 1 g). En el archivo `_a` aparece una rotación alrededor del eje Z.

Columnas: `timestamp, temp_C, ax_g, ay_g, az_g, gx_dps, gy_dps, gz_dps`
(las columnas del magnetómetro `mx_uT, my_uT, mz_uT` del encabezado quedaron vacías).
