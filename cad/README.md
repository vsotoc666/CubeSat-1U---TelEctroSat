# Diseño CAD

Archivos de AutoCAD (`.dwg`) del CubeSat.

| Archivo | Contenido |
|---------|-----------|
| `modelo_inicial.dwg` | Primer modelo de la estructura |
| `modelo_borrador.dwg` | Modelo borrador |
| `modelo_prueba.dwg` | Modelo de prueba |
| `eps_diseno_v1.dwg` | Diseño del subsistema de potencia (EPS) |
| `propiedades_masa_a.txt`, `propiedades_masa_b.txt` | Reportes de propiedades de masa (volumen, centro de gravedad, momentos de inercia) exportados desde AutoCAD |

Para ver los `.dwg` sin AutoCAD puedes usar [Autodesk Viewer](https://viewer.autodesk.com/) (gratuito, en línea).
